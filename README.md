# Interactive Reasoning Puzzles

A browser-based collection of short, timed logic, pattern-recognition, memory,
and decision-making exercises.

The project is built as a single React interface with several self-contained
puzzles, each with its own state machine, scoring, and reset behaviour.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Built with React and Vite.
